# Quando o módulo de prescrição for fechado

Ao finalizar a prescrição, o usuário prescritor pode fechar o módulo e voltar para a experiência do
PEP do parceiro.

Esse momento pode ser capturado registrando o evento de escuta `core:moduleHide`.
Veja um exemplo de implementação [aqui](/docs/frontend/mdsinapseprescricao-mdhub#quando-o-m%C3%B3dulo-%C3%A9-encerrado)
