# Quando o módulo de prescrição terminou de carregar

Para que seja possível executar os [comandos do MdHub](/docs/frontend/comandos-mdhub)
e registrar/escutar os [eventos do MdHub](/docs/frontend/eventos-mdhub), você precisa saber o
momento em que o módulo da plataforma de prescrição terminou de carregar e já pode ser iniciado.

danger

Não é possível executar os comandos do MdHub e/ou registrar(escutar) os eventos do MdHub
sem que o módulo de prescrição tenha sido completamente carregado.

Para verificar se o módulo terminou de carregar e foi iniciado, leia este artigo [aqui](/docs/frontend/mdsinapseprescricao-mdhub#quando-o-m%C3%B3dulo-%C3%A9-iniciado)
