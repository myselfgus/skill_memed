# Certisign (RemoteId)

* [RemoteId](https://www.certisign.com.br/duvidas-suporte/remoteid)

A integração com certificado RemoteID da Certisign é nativa na Memed, então para que os profissionais prescritores possam assinar as suas receitas digitalmente, basta assinalarem a opção localizada no módulo de prescrição conforme imagem abaixo.

![CertiSign /  RemoteId](https://cdn.memed.com.br/doc/assinatura_digital.png)

Na página de suporte ao médico, temos um tutorial explicativo de como o prescritor pode assinar as receitas digitalmente, ele pode ser encontrado clicando [aqui](https://suporte-medico.memed.com.br/hc/pt-br/articles/8562989259675-Como-assinar-habilitar-o-certificado-RemoteID)
