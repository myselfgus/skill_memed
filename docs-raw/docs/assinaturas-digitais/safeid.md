# SafeID

* [SafeID](https://safeweb.com.br/produtos/safeid)

A integração com certificado SafeID é nativa na Memed, então para que os profissionais prescritores possam assinar as suas receitas digitalmente, basta assinalarem a opção localizada no módulo de prescrição conforme imagem abaixo.

![SafeId](https://cdn.memed.com.br/doc/assinatura_digital_safeid.png)

Na página de suporte ao médico, temos um tutorial explicativo de como o prescritor pode assinar as receitas digitalmente, ele pode ser encontrado clicando [aqui](https://suporte-medico.memed.com.br/hc/pt-br/articles/38700632729499-Como-assinar-habilitar-o-certificado-SafeID)
