# Configurar dados do prescritor

Para configurar os dados do prescritor, temos esse [artigo](/docs/backend/usuario-prescritor#cadastrando-o-prescritor)
onde mostra como cadastrar os dados básicos do usuário prescritor. Aqui os cadastros são feitos via api.

Além dos dados básicos, temos um comando MdHub para cadastrar os endereços do prescritor que sairá no receituário, além
de cadastrar o local e cidade de atendimento do usuário prescritor.

Para saber mais leia esse [artigo](/docs/frontend/comandos-mdhub/set-workplace)

Com esses comandos, o usuário prescritor não precisa preencher os seus dados
e ajuda na experiência do usuário na geração de prescrições com medicamentos especiais (Ex.: Amoxil).
Alguns receituários necessitam de informações adicionais para serem gerados e,
caso o parceiro não envie, o usuário terá de preencher.
