# Como capturar evento de prescrição impressa

O parceiro pode implementar o evento de MdHub que captura os dados de cada prescrição criada pelo usuário
prescritor. Com isso, o parceiro pode ter um controle maior sobre seus dados gerados através da plataforma
da Memed.

Para saber como implementar esse evento, leia este [artigo](/docs/frontend/eventos-mdhub/prescricao-impressa)

A Memed recomenda implementar o evento de [prescrição excluída](/docs/frontend/eventos-mdhub/prescricao-excluida)
em conjunto com esse comando, pois esses são complementares.
