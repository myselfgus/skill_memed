# Como capturar evento de prescrição excluída

O parceiro pode implementar o evento de MdHub que captura os dados de cada prescrição excluída pelo usuário
prescritor. Com isso, o parceiro pode ter um controle maior sobre seus dados excluído através da plataforma
da Memed.

Para saber como implementar esse evento, leia este [artigo](/docs/frontend/eventos-mdhub/prescricao-excluida)

A Memed recomenda implementar o evento de [prescrição impressa](/docs/frontend/eventos-mdhub/prescricao-impressa)
em conjunto com esse comando, pois esses são complementares.
