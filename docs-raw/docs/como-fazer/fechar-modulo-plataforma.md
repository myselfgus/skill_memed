# Como fechar o módulo da plataforma prescrição

Se o módulo de prescrição da Memed estiver no modo
[tela inteira](/docs/modos-de-exibicao#tela-inteira), a Memed
disponibiliza o comando `hide` para fechar o módulo. Para saber mais leia esse
[artigo](/docs/frontend/comandos-mdhub/hide).

Caso o módulo de prescrição da Memed estiver no modo [incoporado](/docs/modos-de-exibicao#incorporado), ou seja,
dentro de um container HTML `<div>`, o parceiro pode fechar o módulo no próprio contexto da aplicação escondendo
o módulo que está dentro da `<div>` via javascript.
