# Profissional pode ter mais de uma especialidade na plataforma da Memed ?

Sabemos que os profissionais da saúde podem ser de diferentes especialidades.

Contudo, no momento, é possível cadastrar apenas uma especialidade por prescritor de um parceiro específico na Memed.
A especialidade é usada para refinar os resultados das buscas dentro da plataforma Memed.
Caso o parceiro não tenha essa informação, recomendamos que deixem como Generalista para que o prescritor possa atualizar o seu cadastro posteriormente dentro da plataforma Memed.
