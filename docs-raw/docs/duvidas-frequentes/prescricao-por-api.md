# A Memed possibilita realizar prescrição por API ?

Não há possibilidade de realizar/criar prescrições via api. Somente via plataforma de prescrição.
Pode-se, no entanto, [consultar](/docs/backend/prescricao#recuperar-o-link-da-receita-digital)
ou [deletar](/docs/backend/prescricao#remover-uma-prescri%C3%A7%C3%A3o) prescrição via api.

A Memed disponibiliza comandos via MdHub para [preencher os medicamentos](/docs/frontend/comandos-mdhub/add-item)
que irão compor a receita digital, e para preencher os [dados do paciente](/docs/frontend/comandos-mdhub/set-patient) na receita digital.
Com isso o processo de elaboração da receita digital é agilizado.
