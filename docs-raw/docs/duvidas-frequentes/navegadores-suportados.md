# Quais navegadores de internet são suportados pela Memed?

Nossa plataforma possui diversas funcionalidades construídas com tecnologia moderna, visando uma melhor experiência do usuário.

Recomendamos sempre o uso de navegadores modernos e atualizados para um bom aproveitamento da nossa prescrição digital. Navegadores desatualizados como IE (Internet Explorer) podem apresentar incompatibilidades com nosso software.
Portanto, não damos suporte a esse tipo de navegador.
