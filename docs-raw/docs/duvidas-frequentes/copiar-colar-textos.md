# Copiar e colar textos de outras fontes

A Memed não recomenda o usuário prescritor copiar textos de outros documento e colar dentro da plataforma
de prescrição.

Se no documento que usuário prescritor está copiando conter uma fonte não utilizada pelo sistema Memed,
irá acontecer alguns problemas, conforme exemplo abaixo:

![copia-cola-fonte](https://cdn.memed.com.br/doc/copia-cola-fonte.png)

Caso o usuário queria utilizar algum texto de outro documento dentro da plataforma, aconselhamos o usuário
copiar os textos do documento, colar os textos em um editor de textos do tipo "bloco de notas",
depois copiar esse texto do bloco notas e realizar o procedimento de colar o dentro da plataforma.

Assim o texto estará sem nenhuma formatação e não ocorrerá nenhum problema.
